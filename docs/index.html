Unraid Docker tab

In the Unraid terminal, run this once. Then open Docker → Add Container → User Templates → Ridepane and fill in the fields.

curl -fsSL https://raw.githubusercontent.com/spikked27/ridepane/main/unraid/ridepane.xml -o /boot/config/plugins/dockerMan/templates-user/ridepane.xml

Docker Compose

Download compose.yaml and .env.example into the same folder. Rename the example to .env, fill it in, then run:

docker compose up -d

The Docker image is published from this project's GitHub Actions workflow. If the image is unavailable during first publication, the repository also includes a local build override: docker compose -f compose.yaml -f compose.build.yaml up -d --build.

OPTIONAL · EXPERIMENTAL

Your actual YouTube account on the car screen.

Full YouTube runs Chromium on Unraid and streams its screen to the car. You can browse the same YouTube website you use on your phone, including playlists, Likes, Watch Later, and subscriptions. On the phone pairing page, open the Full YouTube sign-in link and sign in there once. The browser profile stays on Unraid, so the car does not need your Google password. The Full YouTube entry uses the whole available Tesla browser viewport; the stream's side menu also has a fullscreen control where the client browser permits it.

The app and Chromium now run in one container. For Docker Compose, run docker compose up -d. Only the Ridepane app port is published; it protects the internal browser with the same sign-in and proxies it through your existing HTTPS and WebSocket setup. See the README for Unraid Docker tab setup, browser profile persistence, and optional GPU access.

The remote screen defaults to H.264 at 30 fps, adaptive bitrate up to 8 Mbps, and 320 kbps stereo Opus. Resolution follows the browser viewport. It uses canvas rendering and Web Audio. Tesla browser compatibility, Google sign-in, picture quality, and audio need an in-car test. This mode has different quality controls from Ridepane's Plex and YouTube link player.

IN-CAR CHECKS

See what your car can actually do.

Ridepane's Car checks panel measures the connection from the Tesla browser to your Unraid server and tests whether the browser retains a small cache after reopening. It reports video, fullscreen, storage, and audio capabilities, and can play a quiet channel-by-channel test for stereo, 5.1, or 7.1 speaker routing. The cache test uses generated bytes, not Plex media; current Ridepane playback sends stereo.

Use a valid HTTPS address for access outside your LAN. Your reverse proxy must forward WebSocket connections for video playback.

GOOD TO KNOW

Quality and compatibility

Ridepane re-encodes video for canvas playback, so it does not preserve the original video bit for bit. High (720p/30 fps) is the default; Maximum (1080p/30 fps) needs more CPU and mobile bandwidth. Audio is 320 kbps stereo MP3 at 48 kHz. The app can report how many output channels the car browser exposes; discrete 5.1 or 7.1 requires an in-car capability check. Real Tesla performance depends on the car and software version. YouTube playback is experimental because its stream formats can change.

Tesla supports video on equipped rear screens while driving. Ridepane's front-screen rendering is an unofficial passenger workaround. The driver should never watch or operate it in motion.
